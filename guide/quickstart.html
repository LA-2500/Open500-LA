LA v3.1
Quick Start: Installation

Requirements

  • Akai MPC500.
  • CompactFlash card, FAT formatted.
  • Computer with CF card reader and web browser.
  • Akai MPC500 OS 1.31 update: mpc500_v131_00.zip (Akai Professional).
  • Open500-LA-Firmware-Patcher.html and LA-v3.1.zip (release page).

1. Firmware (One Time)

The add-ons require the LA firmware: Akai OS 1.31 with the Open500 loader resident in flash. The patcher applies a binary patch client-side (JavaScript, no upload, no network access), recomputes the OS CRC-32 and verifies the output against the reference SHA-256 before release.

  1. Extract mpc500.bin from mpc500_v131_00.zip.
  2. Open Open500-LA-Firmware-Patcher.html in a web browser.
  3. Drop mpc500.bin onto the page. Input is validated by size (514,732 bytes), CRC-32 and SHA-256; any other file is rejected.
  4. Status Patched and verified: click Save MPC500.bin.
  5. Copy MPC500.bin to the card root.
  6. Hold SHIFT and power on. Press REC at the prompt. Wait for completion.
  7. Delete MPC500.bin from the card.

The update rewrites the OS region only. The bootloader is not modified. Programs, sequences and samples on the card are not affected. Repeat only for a new firmware version.

2. Add-on Files

The MPC500 loads files in the order they were written to the card. LA.WAV must load first. The zip stores the files in load order. Extract it directly to the card.

WindowsRight-click LA-v3.1.zip > Extract All > Browse > select the card drive (e.g. E:\). Remove any trailing \LA-v3.1 from the destination. Extract.
macOSCopy the zip to the card. Double-click it on the card. Delete the zip.
CF card
└── LA v3.1
    ├── LA.WAV         (first)
    ├── ...
    └── MASTER.WAV     (last; 14 files)
  • Delete any earlier add-on folder first. Do not extract over an existing folder.
  • Do not extract to the computer and copy the folder: the copy order is not preserved.
  • Eject the card before removal.

3. Loading

  1. MODE + PAD 2 (LOAD). Select LA v3.1. DO IT.
  2. Clear memory: Yes = empty memory. No = keep current contents.
  3. Display: LOADING... / LA v3.1 (about 3 s, first load after power-on only). Add-ons active.
Add-ons execute from working RAM; no add-on code is written to flash. Reload after every power-on. With a saved project: load the project, then the add-on folder, clear memory No.

Technical Specifications

TargetAkai MPC500, OS 1.31 (mpc500.bin)
Image size514,732 bytes; OS header at 0x10000, CRC-32 field at 0x10010, OS region 449,196 bytes
Input SHA-2567ba01305b1b2c89701e0d7c1d92973920a76c13d0232d9cbc579767332c2940d
Output SHA-256963ac96b19c51ba8a900611a22301b1f516c6192c0aa0a373878bebcc9639c8e
Patch 1Open500 loader, 1,295 bytes at 0x103EC, written over an all-zero region of the image
Patch 2Hook pointer, 4 bytes at 0x2B328
Akai code distributedNone. The patch contains Open500 data only; the base image is supplied by the user.
Add-on format14 RIFF/WAVE containers carrying native code, 229,564 bytes total; loaded by the MPC500 sample loader in write order
Add-on managerLA.WAV (Open500 HUB); identified by content, not file name
Power-on behaviourLA firmware distinguishes cold boot from folder reload; residual RAM contents are ignored at power-on

Troubleshooting

Erratic add-on behaviourWrong file order. Delete the folder. Extract the zip to the card again.
Error after power-onPower cycle. Reload the add-on folder.
Add-on manager not respondingSHIFT + ERASE/UNDO reloads LA.WAV.
Restore factory OSFlash the original mpc500.bin as in step 1. Removes Open500.
